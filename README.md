About this repository

This repository contains working code in R developed during my dissertation research. It reflects the practical and iterative nature of a long-term academic project, including exploratory analyses, intermediate files, alternative approaches and scripts created at different stages of the research.

The repository has been preserved primarily as an archive of the analytical work rather than reorganised as a polished or fully reproducible software project. Some scripts may therefore depend on local file paths, unavailable research data or packages and objects created elsewhere in the workflow. The underlying data are not included because of access and redistribution restrictions.

Selected figures and outputs are included to illustrate the analyses produced through this work.
